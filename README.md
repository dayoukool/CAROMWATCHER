# Carambole — arbitre vidéo

Application web (PWA) pour la carambole en partie libre : un téléphone filme la table, l'application dit si le point
est valide, classe l'effet (rétro, amorti, naturel, coulé) et note le geste (rectitude, régularité).

- Application : dossier `docs/` (servi par GitHub Pages). Sur Android : ouvrir le lien dans Chrome → ⋮ → « Installer l'application ».
- Moteur d'analyse : `engine.js` (JavaScript pur, sans dépendance).
- Détails techniques, conventions et tests : `CLAUDE.md`.
